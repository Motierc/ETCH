# ETCH

The problem with HTML is that it doesn't support variables and loops and conditions... until now.

Presenting **Esoteric Turing Complete HTML**: a language with the aesthetics of
 HTML but is instead turing complete. 
ETCH supports:
  ✅ Variables
  ✅ While Loops
  ✅ For Loops
  ✅ If/else Blocks
  ✅ Math
  ✅ Compilation to Python

To see the syntax of ETCH, look at /ETCH_files/example.etch

## Making ETCH
When I was told that HTML wasn't made to do math I was appalled, then-me couldn't grasp using a coding language but then not doing math with it. I mean what does it even do then? Year later I learnt about esoteric programming languages and compilers and decided: **"let's make HTML turing complete; how hard can it be?"**. Thus ETCH was born.

ETCH is a side project / experiment.
